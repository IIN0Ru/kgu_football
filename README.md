# kgu_football

경기대학교 축구부 **비공식** 팬 홈페이지 (개인 포트폴리오용).

## 개발 방식: AI 활용 개발

- **사용자**: 기획, 디자인 방향(흑백 유니폼 줄무늬 + 주황 포인트) 결정, 콘텐츠 제공, 결과 검수, AI 간 의견 조율
- **Claude**: HTML/CSS 코드 작성, 화면 검증, 커밋
- **GPT**: 코드 리뷰
- 모든 결정과 변경 내역은 [NOTES.md](NOTES.md)의 개발 로그와 검토 기록에 남깁니다.

## 기술

- HTML, CSS (정적 사이트), 반응형(데스크톱·태블릿·모바일)
- 배포: GitHub Pages (예정)

## 고지

선수 사진과 학교 로고는 사용하지 않으며, 공개된 기사와 대회 기록만 참고합니다. 경기대학교 및 경기대학교 축구부와 관련이 없습니다.
